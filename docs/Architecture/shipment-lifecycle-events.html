Shipment lifecycle events

How a shipment moves from ingestion to customs clearance, as the domain events each bounded context publishes, in time order.

Domain event Optional, or trigger not named in the catalog Asynchronous event Synchronous check or call Re-trigger

Synchronous on purpose

  • Permits approved, compliance current and manifest valid are checked at submission time, never from a stale event.
  • The ICEGATE transmission is a direct call, so the submission timestamp is recorded reliably.
  • The customs response then returns asynchronously.

Loops back

Each time a leg arrives, the Segregation Engine re-evaluates the shipment, so the flow is not strictly linear.

Not shown

  • Document Management (DocumentAttached) and Reporting, which only subscribe.
  • Courier shipments, delivery and payment, which the catalog does not cover.
  • The event that adds commodity lines, which the catalog does not name.

Source: Day 5 Context Map and Domain Event Catalog v1.1, sections 2 to 4. This is design only; none of these business events exist in code yet.
